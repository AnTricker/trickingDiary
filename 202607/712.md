# Relax
- 器材：不要太硬的「花生球」，要能壓下去的材質（滾筒ok、按摩球稍嫌小）
- 用手：直接用手指按壓 推開肌肉
- 視當天練習狀況 ex.練很多就需要大放鬆
> **肌肉有「耐久度」**
> - ex.大練完肌肉緊繃到99% => 需要放鬆到6,70% 肌肉才有新的發揮空間
> - 要去感受自己狀態，知道今天練到幾％、要鬆到幾％
> - 人各有異，可能有些人可以一直練不收操，但也可能會積累許久之後大爆發

> **長長的肌肉有彈性**
> - 按開肌肉 讓新生長的肌肉不是短短的而是能「長長的」這樣才「有彈性」
> - ex. 我的右膝上側問題 => 大腿太緊：老師協助按開大腿外內側之後就好很多 就是重新獲得使用空間
> - ex.脛骨的肌肉練毽子到會痛 => 太緊繃了 拉著周遭的組織：要按到不痛；持續練習＆按開讓肌肉有彈性 是可以到練了不會痛的
